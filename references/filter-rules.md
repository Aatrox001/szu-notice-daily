# 调参指南

日报不准，八成是下面三个地方要改。改完跑 `python scripts/notice_daily.py --all`，
每条公告的去留理由都会打出来，照着看就知道该加哪个词。

## 一、某类通知总是收不到

去 `scripts/notice_daily.py` 找 `DROP_ANY`，看有没有误伤：

```python
DROP_ANY = [
    "答辩公告", "成功举办", "顺利举行", "【通讯】", "名单公示", ...
]
```

**只有软文才会用的组合词才安全。** 反面教材：

| 用过 | 后果 |
|---|---|
| `"职场"` | 把「美丽职场·圳等你来」招聘会误杀了 |
| `"教师"` | 把「教师资格证考试报名」误杀了 |
| `"活动"` | 把「宿舍改造活动报名」误杀了 |

正确姿势是把词加长、加具体：`"教师培训"`、`"求职技巧"`、`"就业系列工作"`。

## 二、收到的东西太多

调高 `THRESHOLD`（原来是 6）。或者把某类整体收窄：

```python
CAP = {"env": 4, "due": 6, "job": 7, "acad": 3, "gain": 4}  # 每块最多显示几条
```

## 三、分类进错了桶

看 `SECTION_META` 和 `classify()`。顺序是有意为之：

1. 讲座类 → 只有本院 + 勾了「学术」才进 `acad`
2. 就业类 → 命中 `JOB_HARD` 就进 `job`（优先于其他判断）
3. 环境 / 机会 / 待办 → 各自关键词

如果某条通知跑错桶，把它特有的词加进对应列表即可。

## 四、人话解释不够贴切

`HUMAN` 是「关键词 → 一句话」。匹配规则是：

1. 先找 `HUMAN_STRONG` 里的词（更具体，如「联合培养」「竞赛」）
2. 再找其余词里最长的
3. 都没命中就用 `HUMAN_BY_SECTION` 的兜底句

所以「3+1+1 联合培养项目宣讲会」不会被解释成普通宣讲会——因为「联合培养」在 STRONG 里。

## 五、字段抽取不准

`FIELD_RULES` 是一组正则，按 时间 / 地点 / 截止 / 谁能参加 / 怎么报名 / 要交什么 / 找谁问 顺序抽。

抽出来的值会经过 `_FIELD_CUT` 清洗——它负责在「三、」「附件」「地点：」这些地方切断，
避免把下一栏的内容混进来。如果某类公告总是抽多或抽少，调这两个地方。
